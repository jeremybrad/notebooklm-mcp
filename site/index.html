Codify: C021 documentation publishing

C021 is a personal tool for keeping selected software repository documentation available for learning in Google NotebookLM.

How it works

The owner selects specific documentation files and destination Google Docs. C021 builds source-referenced bundles, checks the authorized Google account and document permissions, updates those Docs, and verifies the result.

The owner adds the Docs to private NotebookLM notebooks and checks their sources. NotebookLM can then answer questions and generate learning materials such as audio discussions and infographics. Updating a document does not regenerate an existing artifact.

Access and control

The publisher runs locally on the owner’s Mac. It requests Google Drive’s drive.file scope for app-authorized files, rather than full Drive access. Its publication command does not invoke an AI model.

C021 is a personal tool, not an open registration service. Read the privacy notice for its data handling and owner controls.
