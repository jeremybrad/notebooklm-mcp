C021 privacy notice

This notice describes Codify’s C021 repository documentation publisher, a personal tool maintained by Jeremy Bradford.

Information used

C021 reads approved documentation from configured Git repositories and paths. Bundles include the selected text and source/revision references. It uses Google OAuth and the drive.file scope to check the authorized account’s identity, document location, ownership, permissions, content and revisions.

Purpose and sharing

C021 updates the owner’s approved Google Docs and verifies their contents. Google receives the uploaded documentation and the data API requests needed to perform these actions. The owner may add the Docs to private NotebookLM notebooks, where Google processes the sources for questions and learning materials. Google’s services are also subject to their own terms and privacy practices.

The publisher checks for owner-only document permissions and refuses unexpected sharing. This does not prevent the owner from changing sharing afterward. The publisher does not invoke an AI model. Separate assistant-operated reviews and NotebookLM artifact generation are outside the publication command.

Storage and retention

The OAuth refresh grant is stored in an explicitly selected macOS Keychain item. Short-lived access credentials are used in memory. Local configuration holds account/client and destination identifiers. Publication state and receipts retain document IDs, revisions, hashes and operational results; they are designed to exclude access tokens and full Google response bodies.

Selected files and generated bundles may remain locally. Docs and NotebookLM sources remain in the owner’s Google account until removed. There is no automatic retention or deletion schedule.

Owner controls

The owner can change the approved source list, stop publication, revoke Google authorization, and remove Docs or NotebookLM notebooks through those services. Revoking authorization does not remove existing uploads or local files.

Website hosting

This site is hosted by GitHub Pages. GitHub logs visitors’ IP addresses for security. See GitHub’s privacy statement. This site adds no analytics, forms, advertising or third-party scripts.
